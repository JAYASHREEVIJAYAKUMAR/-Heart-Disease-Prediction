
# Heart Disease Prediction System

## Project Overview
This project predicts the possibility of heart disease using Machine Learning.

## Algorithm Used
Random Forest Classifier

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Heart Disease Dataset (heart.csv)

- 303 patient records
- 14 columns
- 13 input features and 1 target column

## Model Performance
Accuracy: 90.16%

## Project Files
1. heart-disease-prediction.ipynb
2. heart.csv

## How It Works
1. Load the heart disease dataset.
2. Preprocess the data.
3. Train the Random Forest model.
4. Evaluate model performance.
5. Predict heart disease based on patient details.
